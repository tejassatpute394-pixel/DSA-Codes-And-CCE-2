## 📌 Overview
This repository contains C++ implementations of fundamental Data Structures and Algorithms as part of the Unit-IV CCE II activity. It includes the mandatory Stack and Queue operations, alongside additional practical experiments and the music player case study to demonstrate version control proficiency using Git.

## 🚀 Mandatory Implementations (Unit-IV)
* `stack_using_array.cpp` - Stack operations (push, pop, peek) using a static array
* `queue_using_array.cpp` - Queue operations (enqueue, dequeue) using a static array
* `stack_using_linkedlist.cpp` - Dynamic stack implementation using pointers
* `queue_using_linkedlist.cpp` - Dynamic queue implementation using pointers

## 🌟 Additional Practical Experiments & Case Studies
As per the bonus criteria of the assignment, this repository also maintains implementations of other course practicals:
* `Music_Playlist.cpp` - Case Study: Music player list implementation
* `binary_search.cpp` - Binary Search algorithm
* `bubble_sort.cpp` - Bubble Sort algorithm
* `complex.cpp` - Complex numbers operations
* `double_linked_list.cpp` - Doubly Linked List data structure
* `Graph_DFS.cpp` - Graph Depth First Search (DFS) traversal
* `hash_table.cpp` - Hash Table implementation
* `linear_search.cpp` - Linear Search algorithm
* `postfix.cpp` - Postfix expression evaluation
